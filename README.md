## 🇷🇺 О программе

**Hide iCloud Open menu A12+ Platinum (macOS)** — приложение для сервисных процедур на iPhone и iPad с чипами **Apple A12 и новее**: подготовка устройства, доставка конфигурации с сервера, post-activation, live-журнал, интерфейс Platinum.

Поддерживаются iOS **15.0 – 26.x** (актуальный диапазон см. в [Windows-сборке](https://github.com/smartmaster35rus-dev/Hide-iCloud-A12-Platinum-win) — там первыми выходят обновления канала доставки).

## 🇬🇧 About

macOS build of the **A12+** service toolkit: device prep, server configuration delivery, post-activation options, Platinum UI. See the [Windows repo](https://github.com/smartmaster35rus-dev/Hide-iCloud-A12-Platinum-win) for the latest iOS channel notes.
